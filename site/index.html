How it works

The server never sees your secrets

Everything is encrypted in your browser with keys that exist only in memory. The server, and the database file it writes to, only ever hold ciphertext.

Every field, the title included, goes into one encrypted blob. A copy of the database, or a compromised server, reveals nothing without your master password.

One password, a chain of keys

  1. Master passwordonly in your head
    Argon2id
  2. Master keyonly in memory
    unwraps
  3. Vault keysone per vault, stored wrapped
    AES-256-GCM
  4. Your loginsdecrypted on screen
  • Slow to guess The master key comes from Argon2id with 64 MiB of memory and 3 passes, as OWASP recommends.
  • Cheap to change A new master password re-wraps the vault keys in one transaction. Your logins aren't touched.
  • Tamper-evident Each value is bound to its row, so ciphertext copied onto another row fails to decrypt.

Features

Small on purpose

The less code there is, the less there is to go wrong. Still, it's the whole thing:

Vaults and logins

Separate vaults for personal and work, search, clone a login, and undo a delete.

Password generator

Strong random passwords from the browser's own cryptographic randomness.

One file to back up

Download a backup, restore it later. A restore always keeps a safety copy of your current vault first.

Desktop app

Install it and open it like any other app. No server to start, no browser to open.

Auto-lock

Locks itself after a while without activity, with a countdown you can change.

See for yourself

A built-in database viewer shows every value exactly as stored, and diagrams explain each algorithm.

English and Portuguese

Every screen is translated, and adding a language is one folder of text files.

Easy on the eyes

Light and dark themes, adjustable text size, and a typeface made for low vision: 0 and O never look alike.

Get started

Running in a minute

Needs Node.js 22.13 or newer, which comes with SQLite built in.

In your browser

Serves the app and its API on this computer only.

$ git clone https://github.com/JoaoGeraldes/jelly-keycap
$ cd jelly-keycap
$ npm install
$ npm run build
$ npm start   # http://127.0.0.1:3000

As a desktop app

Opens in its own window, or builds an installer for your system. 

$ npm install
$ npm run desktop   # open the app
$ npm run package   # build an installer

Your master password can't be recovered, by design. Before putting it on a network, read the security notes.
